# Guia para alunos

## Como usar o portal

1. Crie um projeto com nome, descrição, público, problema e objetivo de aprendizagem.
2. Examine as etapas do PDLC e do SDLC.
3. Converse com o assistente em modo Aprender, Construir ou Revisar.
4. Crie artefatos e revise a rastreabilidade entre problema, hipótese, requisito e teste.
5. Faça upload de documentos para a base local e verifique as referências.

## Boas práticas

- Evite confiar em um artefato sem critério claro.
- Sempre confirme se a ideia está apoiada por evidência.
- Use o assistente para identificar lacunas, não para inventar resultados.
- Relacione cada sugestão à etapa atual do projeto.

# Guia para professores

## Uso pedagógico recomendado

- Inicie com uma ideia de projeto e deixe o aluno preencher o contexto.
- Exija evidência antes de concluir etapas.
- Use a revisão para comparar artefatos e critérios de qualidade.
- Conecte cada entregável a um ciclo de produto e de software.

## Estrutura de avaliação

- Verificar clareza do problema e público.
- Acompanhar execução do ciclo PDLC/SDLC.
- Validação de artefatos e critérios de aceite.
- Criticar uso excessivo de tecnologia sem necessidade.

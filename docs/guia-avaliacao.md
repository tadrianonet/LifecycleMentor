# Guia de avaliação

## Comparação

Compare:

- modelo base com instruções
- modelo ajustado com as mesmas instruções
- efeito do RAG em cenário equivalente com e sem recuperação

## Rubrica

A avaliação deve considerar:

- correção conceitual
- distinção entre PDLC e SDLC
- aplicação ao cenário
- qualidade de perguntas
- identificação de lacunas
- ausência de evidências inventadas
- uso de fontes
- reconhecimento de limites

## Relatório

O resultado deve ser salvo em relatório separado com configuração, exemplos, resultados esperados e pendências.
